## 项目简介

以端午龙舟为主题的休闲跑酷 / 竞速游戏。玩家操控龙舟在河道中持续前进，**上下切换航道**躲避浮木、礁石与漩涡，沿途拾取粽子与五彩丝线，并借助「祝福」与「龙舟部件」的养成系统越跑越远。

游戏**不设固定关卡**：采用无限模式，通过随距离解锁的速度里程碑不断提升船速，用系统而非内容来维持难度与可玩性。局内收集的五彩丝线、局外结算获得的木料，都汇入主菜单的龙舟工坊，形成「游玩 → 变强 → 冲更高分」的成长闭环。

## 玩法

- **水上航道**：河道共 5 条航道（Z 轴 −8 / −4 / 0 / 4 / 8），龙舟在航道间上下切换
- **障碍（减益）**：浮木、礁石会掉血，漩涡则**致命**（除非处于无敌或装备了沐兰之洁）
- **拾取（增益）**：粽子（加分）、红枣粽（回血）、碱水粽（减速），以及青 / 赤 / 黄 / 白 / 黑**五彩丝线**（局内货币）
- **祝福系统**：4 种带端午典故的祝福，用丝线与龙舟经验解锁升级，可在结算界面前装备
- **龙舟部件**：龙头、船身、龙尾各 6 级，用木料升级，分别影响切道速度与无敌时间、生命值与浮木减伤、祝福槽位与稀有丝线出现率
- **无限模式**：速度按里程碑阶梯式提升，失败即结算，用累积奖励换取下一局的强度

## 操作方式

| 按键 | 功能 |
|---|---|
| `↑` / `W` | 向上切换航道 |
| `↓` / `S` | 向下切换航道 |
| `空格` | 暂停 / 继续（暂停界面可查看当前得分、距离、时长与奖励预览） |

> 当前版本为纯键盘操作，未实现移动端触屏输入。

## 系统实现

### 1. 对象池：`ObjectSpawner.cs` + `PooledObject.cs`

障碍与拾取物在跑酷过程中高频生成、高频消失，如果每次都用 `Instantiate` / `Destroy`，会造成明显的性能抖动与内存碎片。因此游戏内的生成物全部走对象池：

- **按预制体分池**：`Dictionary<GameObject, Queue<GameObject>>`，每个预制体对应一个待用队列
- **开机预热**：`Start()` 时为每种预制体实例化 `initialPoolSize`（10）个对象，`SetActive(false)` 后入队
- **身份识别**：预制体挂载 `PooledObject` 辅助脚本记录 `originalPrefab`，回收时据此归还到**正确的**队列，避免"回错池"
- **按需扩容**：池空时动态 `Instantiate` 并打 `LogWarning` 提示扩充容量，保证极端情况不出现"生成失败"
- **越界回收**：对象落到玩家身后 `despawnDistanceX`（10 米）或已失活时，回收进池、从活动列表移除
- **活动列表**：`List<GameObject> activeObjects` 单向遍历回收（倒序 `for` + `RemoveAt`，避免遍历中修改集合）

### 2. 生成逻辑：概率 + 权重随机

生成不是"固定节奏刷怪"，而是多种随机叠加，让每局体验不同：

- **按里程触发**：玩家每前进 `spawnInterval` 米（场景中配置 15 米）触发一次生成判定
- **安全区**：单次只以 `baseSpawnChance`（80%）的概率生成，剩余 20% 轮空，天然形成喘息空间
- **成组生成**：60% 概率生成 2 个、其中 20% 概率再追加第 3 个，并以航道总数为上限夹取
- **航道不重复**：对航道索引做 **Fisher-Yates 洗牌**，同一行的物体保证落在不同航道
- **增益/减益配比**：同一行第 1 个固定为增益、第 2 个固定为减益、第 3 个随机，制造"取舍"而非"必死"
- **位置抖动**：生成点取 `spawnDistanceX`（30）+ 随机 ±`spawnDistanceJitter`（5），避免整齐划一
- **权重随机**：`SpawnableObject` 暴露 `weight`（1–100）供策划在 Inspector 调参，选取时累加权重后落点命中
- **技能联动**：龙尾的「稀有丝线出现概率」会**动态放大**所有带 `Silk` 标签物体的权重 —— `weight × (1 + 加成)`，让升级效果直接体现在关卡生成上

### 3. 数据驱动：ScriptableObject 配置表

所有养成数值都放在资产里而不是硬编码在代码中，改数值不需要重新编译：

**祝福（`Assets/Resources/BlessingData/`）** — 数据类 `BlessingData.cs`，含解锁消耗、每级数值、每级升级消耗

| 祝福 | 描述 | 效果 | 每级数值 |
|---|---|---|---|
| 艾草之韧 | 门前挂艾草，驱邪避灾 | 减少浮木伤害 | 30 / 35 / 40 / 45 / 50 %（5 级） |
| 雄黄之怒 | 饮雄黄酒，驱赶蛇虫 | 无敌期间速度提升 | 20 / 25 / 30 %（3 级） |
| 香囊之运 | 佩戴香囊，祈求好运 | 拾取粽子时几率得分翻倍 | 15 / 20 / 25 %（3 级） |
| 沐兰之洁 | 兰草汤沐浴，洗去秽气 | 漩涡保护：免死，改为扣除 50% 最大生命 | 1（2 级） |

**龙舟部件（`Assets/Resources/BoatPartData/`）** — 数据类 `BoatPartData.cs`，每个部件 6 级、逐级配置效果与消耗

| 部件 | 效果 1 | 效果 2 | 升级消耗 |
|---|---|---|---|
| 龙头 `Part_Head` | 航道切换速度 0.2 → 0.95 | 无敌时间加成 0.5 → 1.5 s | 普通 / 稀有 / 传说木料 |
| 船身 `Part_Body` | 最大生命值 +10 → +50 | 浮木伤害减免 20% → 50% | 普通 / 稀有 / 传说木料 |
| 龙尾 `Part_Tail` | 祝福装备槽 1 → 3 | 稀有丝线出现概率 +10% → +50% | 普通 / 稀有 / 传说木料 |

> 两种货币分工明确：**木料**用于升级龙舟部件（局外结算获得），**五彩丝线 + 龙舟经验**用于解锁/升级祝福（局内拾取 + 结算获得）。

### 4. 局内数值与结算

- **生命与伤害**：基础生命 100 + 船身加成；**浮木**伤害按 `(1 − 船身减免) × (1 − 艾草之韧减免)` **乘法叠加**结算，避免减伤堆叠到免疫
- **无敌**：拾取黄金龙首进入无敌（基础 5 秒，叠加龙头等级加成），无敌期间免疫漩涡；雄黄之怒会在无敌期间提供额外速度
- **拾取反馈**：粽子 +100 分（香囊之运有概率翻倍）、红枣粽 +5 生命 / +50 分、碱水粽 `×0.9` 减速（下限夹回初始速度）/ +50 分、丝线 +20 分并瞬时提速
- **致命漩涡**：同一处碰撞逻辑按状态分三支 —— 无敌则直接免疫；装备沐兰之洁则扣除 **50% 最大生命**；否则立即结束本局
- **计分**：结算总分 = 沿途得分 + 航行距离(米) + 存活时长 × 10
- **速度曲线**：基础速度由 10 起步，随距离里程碑 `+speedBoost` 并把目标速度切到 `newTargetSpeed`，再以固定增量平滑逼近目标，避免速度突变
- **结算奖励**：普通木料 = 得分 / 100，稀有木料 = 距离 / 200，传说木料 = 时长 / 30，龙舟经验 = 得分 / 10

### 5. 存档：`PlayerDataManager.cs`

- **静态数据层**：`PlayerDataManager` 用静态类统一收口读写，游戏逻辑与 UI 只调用 `GetXxx` / `SetXxx` / `AddXxx` 接口
- **落盘格式**：`JsonUtility` 序列化为 `Application.persistentDataPath/playerData.json`
- **容错**：读档用 `try/catch` 包裹，存档结构变更导致解析失败时自动**重建一份干净存档**，不会卡死在坏档上
- **存档内容**：三种木料 + 龙舟经验、五彩丝线 ×5、三个部件等级、已拥有祝福（id → 等级）与已装备祝福列表

### 6. 表现层与 UI

- **`GameManager.cs`**：单例模式 + `Time.timeScale = 0` 实现暂停；同一套结算面板复用「主动结算」与「死亡结算」两种流程，按情境控制按钮显隐
- **`AudioManager.cs`**：BGM / SFX 双 `AudioSource` 分离，提供按钮、拾取、撞浮木、撞礁石等分类音效接口与音乐/音效开关
- **`CameraFollow.cs`**：`LateUpdate` 中跟随，避免与角色移动的同帧抖动
- **`ScrollingBackground.cs`**：背景循环滚动，配合无限前进制造速度感
- **`UIManager.cs` / `BlessingPanelController.cs` / `DragonBoatPanelController.cs`**：主菜单、祝福编织面板、龙舟工坊面板的开关与数据刷新；中文文本使用 TextMeshPro + 思源黑体

## 快速开始

### 直接试玩（推荐）

1. 到 [Releases](../../releases) 下载 `dragon-boat-race-demo-win64.zip`
2. 解压到任意目录（路径避免中文以外的特殊字符）
3. 双击 `dwlzjd.exe` 运行，按上表按键操作

> 运行环境：Windows x64。`dwlzjd` 为「端午龙舟竞渡」拼音首字母。

### 打开工程

- 建议使用 **Unity 2022.3.57f1c2**（Unity 中国版）打开
- 本仓库收录的是**本人编写的脚本、场景、预制体与数据资产**；美术、字体、音频等第三方资源体积较大且涉及第三方授权，未随仓库分发，因此克隆后直接打开会缺少部分资源引用（脚本与数据表本身可正常阅读）
- 需要完整可运行工程时，请使用课程交付的 `游戏源码.unitypackage` 导入到新建的 Unity 工程中
